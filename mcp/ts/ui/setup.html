CCXT Account setup

Connect an exchange account

Add an API key so your AI assistant can show your balances, orders and positions.

This page runs on your own computer.

Its address starts with 127.0.0.1, which means “this computer”. What you type is saved to a file here and used to talk to the exchange you pick. It is never shown to the AI assistant and never sent to CCXT.

1Choose your exchange

The exchange where your account is.

2Create an API key on the exchange

An API key is a separate password for apps. You create it in the exchange’s settings, usually under “API management”. Give it only these permissions:

  • ✓
    Reading: onLets the assistant see balances, orders and positions.
  • ✓
    Trading: only if you want the assistant to place ordersLeave it off for a view-only setup.
  • ✕
    Withdrawals: keep them DISABLEDThis setup never needs to move money out of your account.
  • ✓
    Restrict the key to your IP address, if the exchange offers itThen the key only works from your own connection.

3Enter the key

Choose an exchange first — the boxes it needs will appear here.

4Where does this key work?

Keys are made for one environment. Pick the one you created this key in.

5What may the assistant do?

✓View balances, orders and positions — always included.

Orders will use real money

Set the largest single order the assistant may place. Anything bigger is refused, and every order still asks you to confirm first.
