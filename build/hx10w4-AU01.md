## Deleted: 8 definitions whose call count in the port is 0

Each is also unreachable from the pinned printer (`38e725e4b66`) and from `build/`:

1. `go/v4/exchange_helpers.go` `func PanicMessage(r any) string` \u2014 superseded by `RecoveredError`
   directly above it; no `PanicMessage(` in `src/goTranspiler.ts` or `build/`.
2. `cs/ccxt/base/Exchange.Generic.cs` `public bool isArray(object a)` \u2014 the C# printer emits the inline
   `((x is IList<object>) || (x.GetType().IsGenericType && ...))` form or a local `bool isArray = ...`;
   `Array.isArray(` in `src/csharpTranspiler.ts` is a TS-side type query, not an emission.
3. 6 in `java/.../Helpers.java`: `getArgLong`, `getArgString`, `getArgStringList`, `getArgMap`,
   `mathPow`, `toTypedList`. Slot readers for a typed-param front the Java printer no longer emits
   (`Helpers.getArgX(` = 0 hits in `src/javaTranspiler.ts` and `build/`); `Math.pow` now prints native
   `Math.pow(Double.parseDouble(...), ...)` (`src/javaTranspiler.ts:932-935`) and `toTypedList` was
   replaced by the native typed-list spelling (`build/javaUtilImports.ts:67`). Two stale references
   remain and are harmless: the `'pow'` type-table row in `build/java-local-types.js:1737` and a
   comment in `build/javaUtilImports.ts`.

All eight are runtime API only (Go exported, C#/Java public) \u2014 no generated file changes, so the
measured delta is 0 in every port (see below). The win is 8 dead definitions; it is not a call-site
removal.

## What this says for the next wave

- Runtime deletion is exhausted: nothing else is at 0 sites in a port, and everything else is either
  a live printer arm or a hand-written-base/test API.
- The <=6-site families are dominated by two causes: an `any`/`Object` operand produced by a base method
  (`SafeString`, `ParseToNumeric`, the `handleOptionAndParams` tuple, the `currencies` field) and print
  arms that only fire on literal arguments (`padStart/padEnd`, `toFixed`, Rust `Value` predicates).
  Typing those producers, or the printer arm, is the lever \u2014 not deletion.
- `GetArg*`/`PanicOnError` plumbing is still 21967 of the 38573 Go transpiled occurrences; the
  campaign's plumbing rule keeps it out of scope.
