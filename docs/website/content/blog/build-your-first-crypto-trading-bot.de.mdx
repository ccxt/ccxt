Jeder Trading-Bot beginnt mit denselben vier Schritten: mit einer Exchange verbinden, ihre Märkte
laden, ein paar Daten lesen, eine Order platzieren. Dieses Tutorial macht genau das – und weil
CCXT dieselbe API in sechs Sprachen ausliefert, wird jeder Schritt unten in allen gezeigt. Such dir
deinen Tab aus und bleib dabei.

## Regel null: lern nicht mit echtem Geld

Bevor du irgendeinen Code schreibst:

- **Nutze ein Testnet.** Die meisten großen Exchanges (Binance, Bybit, OKX und andere) bieten
  Sandbox- oder Demo-Umgebungen mit Spielgeld an. CCXT schaltet mit einem einzigen Call darauf um –
  `setSandboxMode(true)` – siehe unten.
- **Erstelle API-Keys mit deaktivierten Auszahlungen** und einer IP-Allowlist. Ein Trading-Bot
  braucht nie Auszahlungsberechtigungen.
- **Fang mit der Mindestordergröße der Exchange an**, auch auf dem Testnet, damit sich die
  Gewohnheiten übertragen.

## Schritt 2 – verbinden und Märkte laden

`loadMarkets()` lädt die handelbaren Symbole, Präzisionsregeln und Limits der Exchange herunter.
Ruf es einmal beim Start auf; alles Weitere baut darauf auf.

```javascript tab="JavaScript"
import ccxt from 'ccxt';

const exchange = new ccxt.binance({
    apiKey: process.env.API_KEY,
    secret: process.env.SECRET,
});
exchange.setSandboxMode(true); // Testnet — nur entfernen, wenn du es wirklich meinst

await exchange.loadMarkets();
console.log(`${exchange.id}: ${Object.keys(exchange.markets).length} markets`);
```

```python tab="Python"
import os
import ccxt

exchange = ccxt.binance({
    'apiKey': os.environ['API_KEY'],
    'secret': os.environ['SECRET'],
})
exchange.set_sandbox_mode(True)  # Testnet — nur entfernen, wenn du es wirklich meinst

exchange.load_markets()
print(exchange.id, len(exchange.markets), 'markets')
```

```php tab="PHP"
<?php
$exchange = new \ccxt\binance([
    'apiKey' => getenv('API_KEY'),
    'secret' => getenv('SECRET'),
]);
$exchange->set_sandbox_mode(true); // Testnet — nur entfernen, wenn du es wirklich meinst

```


Der Rate Limiter von CCXT ist **standardmäßig aktiv** – Requests werden automatisch so verteilt,
dass die Limits der Exchange eingehalten werden, eine einfache Schleife bringt deiner IP also
keinen Bann ein.

Achte auf das Symbol: `BTC/USDT` ist das **Unified-Symbol**-Format von CCXT. Du schreibst auf
jeder Exchange dasselbe Symbol – CCXT übersetzt es in das, was die Exchange intern verwendet
(`BTCUSDT`, `XBTUSDT`, `BTC-USDT`, ...).

## Schritt 4 – eine Limit-Order platzieren und wieder stornieren

Wir platzieren eine Kauforder 20 % unter dem Marktpreis, damit sie nicht ausgeführt wird, während
du experimentierst, und stornieren sie dann.

```javascript tab="JavaScript"
const price = exchange.priceToPrecision('BTC/USDT', ticker.last * 0.8);
const amount = 0.001;

const order = await exchange.createOrder('BTC/USDT', 'limit', 'buy', amount, price);
console.log('placed:', order.id);

await exchange.cancelOrder(order.id, 'BTC/USDT');
console.log('canceled');
```

```python tab="Python"
price = exchange.price_to_precision('BTC/USDT', ticker['last'] * 0.8)
amount = 0.001

order = exchange.create_order('BTC/USDT', 'limit', 'buy', amount, price)
print('placed:', order['id'])

exchange.cancel_order(order['id'], 'BTC/USDT')
print('canceled')
```

```php tab="PHP"
$price = $exchange->price_to_precision('BTC/USDT', $ticker['last'] * 0.8);
$amount = 0.001;

$order = $exchange->create_order('BTC/USDT', 'limit', 'buy', $amount, $price);
echo 'placed: ', $order['id'], "\n";

$exchange->cancel_order($order['id'], 'BTC/USDT');
echo "canceled\n";
```

```csharp tab="C#"
var price = (double)ticker.last * 0.8;
var amount = 0.001;

var order = await exchange.CreateOrder("BTC/USDT", "limit", "buy", amount, price);
Console.WriteLine($"placed: {order.id}");

await exchange.CancelOrder(order.id, "BTC/USDT");
Console.WriteLine("canceled");
```

```go tab="Go"
price := *ticker.Last * 0.8
amount := 0.001

order, err := exchange.CreateOrder("BTC/USDT", "limit", "buy", amount,
    ccxt.WithCreateOrderPrice(price))
if err != nil {
    panic(err)
}
fmt.Println("placed:", *order.Id)

_, err = exchange.CancelOrder(*order.Id, ccxt.WithCancelOrderSymbol("BTC/USDT"))
if err != nil {
    panic(err)
}
fmt.Println("canceled")
```

```java tab="Java"
double price = ticker.last * 0.8;
double amount = 0.001;

var order = exchange.createOrder("BTC/USDT", "limit", "buy", amount, price, null);
System.out.println("placed: " + order.id);

exchange.cancelOrder(order.id, "BTC/USDT", null);
System.out.println("canceled");
```

Zwei Details, die Spielzeugskripte von echten Bots unterscheiden, beide hier sichtbar:

- **Präzisionshelfer.** `priceToPrecision` / `amountToPrecision` runden Werte auf das, was die
  Exchange tatsächlich akzeptiert. Wer `26418.377777` roh schickt, bekommt seine Order abgelehnt.
- **Übergib `cancelOrder` immer das Symbol.** Viele Exchanges verlangen es, und Unified-Code
  sollte davon ausgehen, dass es gebraucht wird.

  Exchanges, Spot und Derivate, öffentliche und private Endpunkte.
